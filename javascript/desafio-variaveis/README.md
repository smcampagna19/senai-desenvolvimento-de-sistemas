# 🚀 Desafio de Código – JavaScript Variáveis

Bem-vindo ao seu primeiro desafio de programação inspirado em **processos seletivos de empresas de tecnologia**.

Neste desafio você deverá completar um código JavaScript que simula um **sistema simples de cadastro e avaliação de aluno**.

---

# 🧠 Conceitos praticados

Neste exercício você deverá utilizar:

✔ Armazenamento de dados em variáveis  
✔ Declaração e inicialização de variáveis  
✔ Escopo de variáveis  

---

# 🎯 Objetivo

Completar o arquivo `desafio.js` para que o programa:

1. Armazene informações de um aluno
2. Calcule a média de duas notas
3. Informe se o aluno foi aprovado ou reprovado

---

# 📂 Estrutura do projeto
desafio-js-variaveis
│
├── README.md
└── desafio.js


---

# ⚙️ Pré-requisitos

Instalar:

- Node.js
- VS Code
- Git

Verifique no terminal:
node -v


---

# 📥 Clonando o projeto

No terminal do VS Code:
git clone LINK_DO_REPOSITORIO

Entre na pasta:
cd DESAFIO-JS-VARIAVEIS

No Terminal Rode:
code .


---

# ▶️ Executando o projeto

No terminal:
node desafio.js


---

# 🧩 O desafio

Você receberá um **código incompleto**.

Sua tarefa será:

- completar as variáveis
- calcular a média
- criar a lógica de aprovação
- mostrar os resultados no console

---

# 📋 Regras

Você deve obrigatoriamente usar:

- `let` para criar variáveis
- variáveis para armazenar dados
- escopo dentro de um `if`

---

# 📌 Critérios de aprovação

Seu programa deve mostrar algo parecido com:
Aluno: Maria
Nota 1: 7
Nota 2: 8

Média: 7.5
Resultado: Aprovado

---

# 🧠 Resultado esperado

Aluno: João
Nota 1: 8
Nota 2: 7

Média: 7.5
Resultado: Aprovado
