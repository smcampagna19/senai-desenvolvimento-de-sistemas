📄 Descrição das Atividades
Atividade 1 — Sistema de Média Escolar
Calcula a média de um aluno e verifica se ele foi aprovado ou reprovado com base na regra escolar.

Regra: Média mínima para aprovação = 7
Conceitos: constantes, cálculo de média, condição de aprovação


Atividade 2 — Sistema de Velocidade de Jogo
Demonstra como jogos utilizam constantes para controlar comportamentos como velocidade de personagens.

Regra: Velocidade inicial = 10
Conceitos: constantes em contexto de jogos


Atividade 3 — Sistema de Limite de Usuários
Controla o número de usuários online, aplicando uma regra de limite máximo do sistema.

Regra: Máximo de usuários online = 100
Conceitos: regras de sistema, validação de limites


Atividade 4 — Sistema de Frete Grátis
Simula a lógica de um e-commerce que oferece frete grátis a partir de um valor mínimo de compra.

Regra: Frete grátis em pedidos acima de R$ 150
Conceitos: lógica de negócio, condicionais, e-commerce


Atividade 5 — Sistema de Pontuação de Jogo
Cria uma lógica simples de classificação de jogadores com base na pontuação obtida.

Conceitos: lógica de classificação, condicionais


Atividade 6 — Sistema de Cadastro com Idade Mínima
Valida se um usuário possui a idade mínima necessária para realizar um cadastro no sistema.

Regra: Idade mínima para cadastro = 18 anos
Conceitos: constantes, condições, regras de sistema


Atividade 7 — Sistema de Compra com Desconto ⭐
Sistema mais completo, simulando um fluxo real de compra com cálculo de desconto automático.

Regras:

Produto = R$ 50
Taxa de entrega = R$ 10
Pedidos acima de R$ 200 ganham desconto de R$ 20


Desafio implementado:

✔ Nome do cliente
✔ Exibição do valor dos produtos
✔ Taxa de entrega exibida separadamente
✔ Desconto aplicado e mostrado ao cliente


Conceitos: constantes, cálculo, lógica de negócio completa
