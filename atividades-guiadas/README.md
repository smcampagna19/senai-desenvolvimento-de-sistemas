# Atividades Guiadas

Esta pasta reúne atividades desenvolvidas com orientação em aula.

## Objetivo

Separar atividades guiadas dos projetos principais do repositório, preservando o histórico de prática e evolução durante o curso.

## Conteúdo sugerido

```txt
atividades-guiadas/
├── atividade-guiada-05/
├── css/
├── landingpage/
├── mural-musical/
└── versionamento/
```

## Observação

Essas atividades servem como registro de aprendizado e prática, mesmo que não sejam os projetos principais do repositório.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Git e GitHub, quando necessário
