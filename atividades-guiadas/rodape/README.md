# Portfólio Pessoal

Atividade Hands-On de criação de uma landing page pessoal usando HTML, CSS e Bootstrap.

## Sobre o projeto

O projeto é um portfólio simples para apresentar informações pessoais, habilidades, projetos e uma página de contato.

## Páginas

- index.html: página inicial do portfólio
- sobre.html: informações sobre mim e habilidades
- projetos.html: projetos em destaque
- contato.html: formulário de contato
- style.css: estilos do site

## Tecnologias usadas

- HTML
- CSS
- Bootstrap
- Bootstrap Icons

## Como abrir

Abra o arquivo index.html no navegador.
